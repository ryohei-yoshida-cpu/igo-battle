# 九路 Blitz

9路盤の対局アプリ（ウェブ版・試作）。最終的にはAndroidアプリとしてリリースする予定。

## 遊び方

`index.html` をブラウザで開く（GitHub Pages で公開するとスマホからそのまま遊べます）。

## いまできること

- タイトル画面：幽玄の間のような和室に桜吹雪
- 9路盤・コミ7目（同点は持碁＝引き分け、レートは0.5勝で計算）・中国ルールの数え方
- 持ち時間 5分 + 1手ごとに5秒加算。時間切れは負け
- ランダムマッチ：8秒探して相手がいなければ Bot（10級〜1級）とマッチ
  - 「Botとはマッチしない」切り替え（人と対戦するサーバーは準備中のため、オンだと待ち続ける）
  - 待ち時間中に検討モードに入れる
  - Bot の1手は5秒以内。相手の手番中に先読みし、その読みを引き継ぐ
  - Bot は負けがはっきりすると投了する。相手がパスした後は、ツナギ・コウの解消・ダメ詰めだけを打つ
- ホーム：対人戦・ソロストーリーモード（大）／検討モード・キャラクター・戦績と棋譜（横長）／設定は右下の歯車
- 読む画面：ログ（タップでその場面から再開）、登場人物（ここまでに出た人だけ）、実戦へ ≫。話す人が変わると名前の位置が左右入れかわる
- 長い幕は約30行ずつに区切り、区切りごとにミッション（新しいレクチャーと実戦ドリルを交互に）
- 実戦ドリル：自動生成した180問（`drills.js`）。Lv.1〜6の6段階・各30問で、易しい順に進む。ミスなしの正解6問でレベルアップ、同じ問題は一巡するまで出ない。回転・反転して同じ形は1つだけ。全問エンジンで正解確認済み
- マイルーム：勝つと「銭」がもらえる（Bot戦は強いほど多い、対人戦80、ソロの実戦30、レクチャー初クリア20、ドリル正解3）。銭で家具（和洋中 約40種）・床・壁紙を買い、12×12マスの部屋にドラッグで飾る。回転・しまう・電気のオンオフ。碁盤をタップで対局。自分のキャラは通算5勝、ほかのキャラはそのキャラに5勝で遊びに来て、部屋や家具にあわせたセリフ（全120通り、`room-lines.js`）を話す。「一局打つ」でそのキャラと対局（`room.js` / `room-art.js`）
- ソロモード：物語3本（`stories.js`）と読み物の脚本3本（最後のイッキョク／郷愁のレゾンデートル／図書の子）を読み、幕の区切りでミッションをクリアすると続きが読める
  - 初心者：小春と玄斎のレクチャー23項目・実戦問題46問（`lessons.js`）。幕の区切りで大きく「実戦！」と出る
  - 経験者：Botの強さを選んで対局し、勝てば続きが読める（レートは変わらない）
- レート：囲碁クエスト9路の段級基準（10級=1050 … 1級=1600、初段=1700）
  - 上がり幅は Elo 方式（最初の20局は K=32、その後 K=16）
  - 初段以上への昇段はレート到達＋4連勝が必要
- キャラクター：画像イラスト7人（`img/`）。小春・玄斎のほか、ひなた・静馬・巴・みけ＆こむぎ・殿。全員アバターに選べ、Botの強さで対局相手が変わる（10級みけ＆こむぎ → 1級玄斎）
- 技のカットイン：キャラのイラストと技名が帯ごと飛び込む（将棋ウォーズ風）
- タップの演出：どこをタップしても光と花びら、着手はさらに大きな光・音・振動
- 盤のデザイン：榧の盤／和紙（半透明）
- 検討モード、AIの次の一手（1級程度なので初心者向けの参考）
- アバター変更（キャラ7人）、名前変更、レートリセット
- 切断ルール：対局中にアプリを閉じたら負け、通信が3分切れたら負け

## 対人戦（Cloudflare）

人どうしの対戦は Cloudflare Workers ＋ Durable Objects（無料プランで動く）で動きます。

- `server/core.js` … マッチング・手の中継・時計（サーバーが正）・切断3分で負け・再接続で再開
- `server/worker.js` … Cloudflare の入口。`/ws` が対人戦、それ以外はアプリのファイルを配る
- `server/dev.mjs` … 手元で試すとき用（`node server/dev.mjs` → http://localhost:8787）
- `wrangler.toml` / `.assetsignore` … Cloudflare の設定
- `.github/workflows/deploy.yml` … main に push すると自動で Cloudflare に公開
- `config.js` … GitHub Pages など別の場所で開くときの、サーバーの住所
- アカウント：はじめて開くとサーバーが ID とパスワード（各8文字）を作り、保存データ（名前・レート・戦績・進み具合）をサーバーにも保存する。設定画面の「アカウント」から確認でき、別の端末で入力すると引き継げる。保存先は Durable Object のストレージ（パスワードはハッシュで保存）

### はじめての公開（1回だけ）

GitHub Actions が Cloudflare に公開する（Cloudflare の「Connect GitHub」は使わない）。

1. Cloudflare → 右上の人のアイコン →「My Profile」→「API Tokens」→「Create Token」→「Edit Cloudflare Workers」の「Use template」
2. 「Zone Resources」（Edit Zone policy）の「Specific zone」を「All zones」に変える
3. 一番下の「Continue to summary」→「Create Token」→ 出てきたトークンをコピー
4. GitHub の igo-battle →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で2つ登録
   - `CLOUDFLARE_API_TOKEN` … 3 のトークン
   - `CLOUDFLARE_ACCOUNT_ID` … Cloudflare の「Workers & Pages」画面の Account details にある Account ID
5. GitHub の「Actions」タブ →「Deploy to Cloudflare」→「Run workflow」
6. 数分で `https://igo-battle.<サブドメイン>.workers.dev` が開けるようになる

以後は push するたびに自動で更新される。


## 銭とマイルーム（サーバーが正）

- 銭・持っている家具・部屋の配置は、サーバー（`server/core.js`）だけが書きかえる。アプリから送られた銭の数は使わない
- 対人戦：サーバーが結果を知っているので、勝ち80・持碁40をサーバーが出す（8手未満は出さない）
- Bot戦：開始をサーバーに記録し、30秒未満・16手未満の勝ちは数えない。Bot戦の銭は1日600まで
- レクチャー初クリア20・ドリル3は、1つにつき1回だけ
- ショップの値段は `server/prices.js`（`room-art.js` のカタログと同じにする）。買えるかはサーバーが判断
- 部屋の配置は「もようがえを終わる」・部屋を出る・床や壁紙を変えたときだけ送る。持っていない家具が置かれていたら受けつけない

## ほかのゲーム（将棋・オセロなど）と共有するもの

| 共有する（`common/` と `server/social.js`） | このゲームだけ |
|---|---|
| アカウント（ID・パスワード）、銭 | レート・段級・戦績と棋譜 |
| アバター（顔・髪・体・上・下・靴）と持っているパーツ | キャラクター（小春・玄斎…）とストーリー |
| マイルーム（家具・床・壁紙）と部屋番号 | 部屋に遊びに来るキャラとセリフ（room-lines.js） |
| 日記・コメント・一言チャット・訪問数・足あと | ソロモード・ドリル |
| フレンド・ブロック・コメント設定・NGワード（server/ng.js） | |

- アプリ側：`common/avatar-art.js`（アバターの絵とカタログ）、`common/avatar.js`（着せかえ画面）、`common/room-art.js`（部屋と家具の絵）、`common/social.js`（日記・チャット・交流のパネル）
- サーバー側：アカウント `acct:<ID>` の `zeni / owned / room / av / pid / name` は全ゲーム共通。`data` はゲームごとのセーブ（今は囲碁）。交流は `soc:<ID>`、部屋番号は `pid:<番号>`。
- 新しいゲームを作るときは、同じ Worker（同じ Durable Object）に `t:'soc'` と `buy` を送れば、同じアバターと部屋が使える。

## 荒らし対策
- ブロック：相手は部屋に入れない・書きこめない。フレンドも解除、その人の書きこみも消える
- コメント設定：全員／フレンドだけ／受け付けない（日記コメントと一言チャット）
- NGワード：性的・暴力的・悪口や差別語・URLや電話番号などの連絡先。ひらがな・カタカナ・空白はさみもそろえて調べる
- 書きこみは4秒に1回・1日80回まで。部屋の持ち主はどの書きこみも消せる
