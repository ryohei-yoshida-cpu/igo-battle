# 九路 Blitz

9路盤の対局アプリ（ウェブ版・試作）。最終的にはAndroidアプリとしてリリースする予定。

## 遊び方

`index.html` をブラウザで開く（GitHub Pages で公開するとスマホからそのまま遊べます）。

## いまできること

- 9路盤・コミ7目（同点は持碁＝引き分け、レートは0.5勝で計算）・中国ルールの数え方
- 持ち時間 5分 + 1手ごとに5秒加算。時間切れは負け
- ランダムマッチ：8秒探して相手がいなければ Bot（10級〜四段）とマッチ
  - ホーム画面で「Botの強さ」を選べる（自動＝自分のレートの近く、または10級〜四段を指定）
  - Bot は負けがはっきりすると投了する（勝率8%未満、または15目以上の差）
  - Bot は駄目・コウ・アタリの石が残っている間はパスしない
  - Bot の段級は、実際に打った感触に合わせて3段階繰り下げ済み（以前の四段 ≒ 初段）
- レート：囲碁クエスト9路の段級基準（10級=1050 … 1級=1600、初段=1700）
  - 上がり幅は Elo 方式（最初の20局は K=32、その後 K=16）
  - 初段以上への昇段はレート到達＋4連勝が必要
- 技エフェクト：ツケ・ハネ・ノビ・コスミ・ツナギ・キリ・アタリ・ポン抜き・コウ取り・一間トビ・ケイマ・星・小目・天元 など
- 検討モード：対局後の「検討する」、最近の対局をタップ、またはホームの「検討モード」から。1手ずつ進める／戻す、自由に打って変化図を作る、本譜に戻る
  - 「AIの次の一手」：一番強い設定で約5秒読み、候補手を3つ表示（AIはまだ初段程度なので初心者向けの参考）
- アバター変更（プリセット12種／写真）、名前変更、レートリセット
- 切断ルール：対局中にアプリを閉じたら負け、通信が3分切れたら負け

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | デザイン |
