# 九路 Blitz

9路盤の対局アプリ（ウェブ版・試作）。最終的にはAndroidアプリとしてリリースする予定。

## 遊び方

`index.html` をブラウザで開く（GitHub Pages で公開するとスマホからそのまま遊べます）。

## いまできること

- タイトル画面：幽玄の間のような和室に桜吹雪
- 9路盤・コミ7目（同点は持碁＝引き分け、レートは0.5勝で計算）・中国ルールの数え方
- 持ち時間 5分 + 1手ごとに5秒加算。時間切れは負け
- ランダムマッチ：8秒探して相手がいなければ Bot（10級〜1級）とマッチ
  - 「Botとはマッチしない」切り替え（人と対戦するサーバーは準備中のため、オンだと待ち続ける）
  - 待ち時間中に検討モードに入れる
  - Bot の1手は5秒以内。相手の手番中に先読みし、その読みを引き継ぐ
  - Bot は負けがはっきりすると投了する。相手がパスした後は、ツナギ・コウの解消・ダメ詰めだけを打つ
- ホーム：対人戦・ソロストーリーモード（大）／検討モード・キャラクター・戦績と棋譜（横長）／設定は右下の歯車
- 読む画面：ログ（タップでその場面から再開）、登場人物（ここまでに出た人だけ）、実戦へ ≫。話す人が変わると名前の位置が左右入れかわる
- 長い幕は約30行ずつに区切り、区切りごとにミッション（新しいレクチャーと実戦ドリルを交互に）
- 実戦ドリル：自動生成した210問（`drills.js`、1手で取る／追いかけて取る／アタリから逃げる。全問エンジンで正解確認済み）
- ソロモード：物語3本（`stories.js`）と読み物の脚本3本（最後のイッキョク／郷愁のレゾンデートル／図書の子）を読み、幕の区切りでミッションをクリアすると続きが読める
  - 初心者：小春と玄斎のレクチャー23項目・実戦問題46問（`lessons.js`）。幕の区切りで大きく「実戦！」と出る
  - 経験者：Botの強さを選んで対局し、勝てば続きが読める（レートは変わらない）
- レート：囲碁クエスト9路の段級基準（10級=1050 … 1級=1600、初段=1700）
  - 上がり幅は Elo 方式（最初の20局は K=32、その後 K=16）
  - 初段以上への昇段はレート到達＋4連勝が必要
- キャラクター：画像イラスト7人（`img/`）。小春・玄斎のほか、ひなた・静馬・巴・みけ＆こむぎ・殿。全員アバターに選べ、Botの強さで対局相手が変わる（10級みけ＆こむぎ → 1級玄斎）
- 技のカットイン：キャラのイラストと技名が帯ごと飛び込む（将棋ウォーズ風）
- タップの演出：どこをタップしても光と花びら、着手はさらに大きな光・音・振動
- 盤のデザイン：榧の盤／和紙（半透明）
- 検討モード、AIの次の一手（1級程度なので初心者向けの参考）
- アバター変更（キャラ7人）、名前変更、レートリセット
- 切断ルール：対局中にアプリを閉じたら負け、通信が3分切れたら負け

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | デザイン |
| `art.js` | キャラクター一覧・和室の背景・桜吹雪・タップの光 |
| `img/` | キャラクター画像（`名前.jpg`＝上半身、`名前_face.jpg`＝顔） |
| `app.js` | 画面の動き・対局の進行・レート |
| `solo.js` | ソロモード（脚本の表示・ミッション・レクチャー） |
| `stories.js` | ソロモードの物語3本 |
| `scripts.js` | 台本形式（`名前「セリフ」`、ト書きは（ ））の脚本を読みこむしくみ |
| `story_*.js` | 読み物の脚本（`addScript(...)` で追加。新しい脚本もこの形で増やせる） |
| `lessons.js` | レクチャーの説明と実戦問題 |
| `engine.js` | 囲碁のルール判定と Bot（1級は1手4.5秒以内、相手の手番中も先読み） |
