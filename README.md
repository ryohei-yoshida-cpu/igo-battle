# 九路 Blitz

9路盤の対局アプリ（ウェブ版・試作）。最終的にはAndroidアプリとしてリリースする予定。

## 遊び方

`index.html` をブラウザで開く（GitHub Pages で公開するとスマホからそのまま遊べます）。

## いまできること

- 9路盤・コミ7目（同点は持碁＝引き分け、レートは0.5勝で計算）・中国ルールの数え方
- 持ち時間 5分 + 1手ごとに5秒加算。時間切れは負け
- ランダムマッチ：8秒探して相手がいなければ Bot（10級〜1級）とマッチ
  - ホーム画面で「Botの強さ」を選べる（自動＝近い強さ、または10級〜1級を指定）
  - 待ち時間中に「Botとはマッチしない」を切り替えられる（人と対戦するサーバーは準備中のため、オンだと待ち続ける）
  - 待ち時間中に検討モードに入れる（相手が見つかると自動で対局へ）
  - Bot の1手は5秒以内。相手の手番中に先読みし、その読みを引き継ぐ
  - Bot は負けがはっきりすると投了する（勝率8%未満、または15目以上の差）
  - 相手がパスした後の Bot は、自分のアタリのツナギ・コウの解消・ダメ詰めだけを打ち、自陣の死に石は抜かない
- レート：囲碁クエスト9路の段級基準（10級=1050 … 1級=1600、初段=1700）
  - 上がり幅は Elo 方式（最初の20局は K=32、その後 K=16）
  - 初段以上への昇段はレート到達＋4連勝が必要
- 宇宙テーマ：銀河の背景に透明な盤（設定で木の盤に戻せる）。フォントは M PLUS Rounded 1c（極太の丸ゴシック）
- メインキャラ：宇宙人「ノクス」（色違い8種がアバター）。相手のBotはロボット
- 技のカットイン：キャラのイラストと技名が帯ごと飛び込む（将棋ウォーズ風）。ツケ・ハネ・ノビ・コスミ・ツナギ・キリ・アタリ・ポン抜き・コウ取り・一間トビ・ケイマ・星・小目・天元 など
- 検討モード：対局後の「検討する」、最近の対局をタップ、またはホームの「検討モード」から。1手ずつ進める／戻す、自由に打って変化図を作る、本譜に戻る
  - 「AIの次の一手」：一番強い設定で5秒以内に読み、候補手を3つ表示（AIは1級程度なので初心者向けの参考）
- アバター変更（宇宙人の色違い8種／写真）、名前変更、レートリセット
- 切断ルール：対局中にアプリを閉じたら負け、通信が3分切れたら負け

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `art.js` | キャラクターのイラストと銀河の背景（すべてコードで描画） |
| `style.css` | デザイン |
| `app.js` | 画面の動き・対局の進行・レート |
| `engine.js` | 囲碁のルール判定と Bot（モンテカルロ木探索。1級は1手4.5秒以内、相手の手番中も先読み） |
